Guide · Ten-second pause

How to pause before opening a distracting website.

A ten-second pause adds a clear moment between opening a site and continuing. Here is how to set that boundary for one site in Little Pause.

Version note: these instructions describe Little Pause 3.1.0. The Chrome Web Store currently offers Talk to Unlock 3.0.1 with an earlier interface. Compare the installation options.

This setup is intentionally narrow: choose one domain, start with the default pause, and change the rule only if you learn that you need a different kind of help.

1. Install Little Pause

Download the current build from the Chrome installation page, turn on Developer mode, and load the folder that contains manifest.json. These steps install Little Pause 3.1.0; the store release uses the earlier Talk to Unlock interface.

2. Add the site you want to pause

Open the Little Pause popup, choose My sites, and add the domain you want to change. For example, use youtube.com for YouTube. Include subdomains only when they are part of the boundary you want.

3. Choose Take a pause

Select Take a pause and save the rule. New rules start with a ten-second pause, so the everyday flow stays simple. The extension does not create a preset list for you; you decide which sites are included.

4. Start the pause when the blocker appears

When you open the selected site, Little Pause shows its blocker. Press the explicit Start pause button, keep the tab visible while the timer runs, and then decide whether to continue. The pause itself does not make a productivity claim or record your words.

5. Choose a stronger or more deliberate boundary when needed

Open the site rule’s More options if a timed pause is not enough. Say a phrase adds an optional voice check. Keep blocked keeps the site closed under the normal rule. Schedules, daily allowances, cooldowns, unlock duration, and Focus behavior are also configured per site.

If you need to continue right away

When emergency access is enabled for the rule, the blocker keeps a five-second hold-to-confirm action under Need to continue?. An interrupted hold does not unlock the site. A completed bypass uses the rule’s normal unlock window and is recorded in local activity.

Good starting point: protect one site for one day, keep the ten-second default, and notice whether the extra moment changes what you choose. You can adjust or remove the rule at any time.

Common fixes

  • If the blocker does not appear, confirm protection is on, the rule is active, and its schedule is currently open.
  • If a subdomain is not covered, turn on Include subdomains in More options.
  • If Focus is active, check whether the site’s Keep this site blocked during Focus sessions option is enabled.
  • If the page was already open when you changed the rule, reload it.
