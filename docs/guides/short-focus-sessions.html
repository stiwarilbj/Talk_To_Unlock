How to use short Focus sessions.

A focus session does not need to be heroic. A small, protected block is often enough to begin the thing in front of you.

Version note: these instructions describe Little Pause 3.1.0. The Chrome Web Store currently offers Talk to Unlock 3.0.1 with an earlier interface. Compare the installation options.

Little Pause’s Focus timer is a simple browser control: choose a duration, start it from the popup, and let opted-in site rules stay protected until it ends.

Choose the smallest useful block

Little Pause offers 25 minutes, 50 minutes, and a custom duration. Start with 25 when you are beginning, switching tasks, or low on energy. Choose 50 when you already know what you want to stay with. Use custom when your next natural stopping point is different.

Set up the next step before pressing start

Write down one visible next action: open the draft, outline the first section, answer three messages, or clear the table. A timer protects a direction; it does not need to invent one.

Start a Focus session

  1. Install Little Pause and add at least one site in My sites.
  2. Open Little Pause from Chrome’s extensions menu.
  3. Choose 25 min, 50 min, or Custom.
  4. Press Start focusing. Sites whose rules opt into Focus stay protected until the session ends.
  5. When you are done, reopen the popup and press End session, or let the timer finish.

Choose which sites Focus protects

Focus behavior is a per-site option. In My sites, open a rule’s More options and enable Keep this site blocked during Focus sessions when that site should stay closed during a session. You can keep a ten-second pause for one site and a firm block for another.

Let the session be ordinary

Notifications, interruptions, and imperfect days happen. If you need a protected site for a real reason, use the rule’s configured emergency hold. If the timer is too long, end it and choose a smaller block next time. The useful part is the clear start, not a perfect streak.

A realistic ritual: choose one task, start 25 minutes, keep your next action visible, and decide what to do when the timer ends. That is enough.

When a shorter pause is better

If you are not ready for a Focus session, use a ten-second site pause instead. Learn how to pause before opening a distracting website or read how to reduce distracting website visits.
