How to block YouTube during a Focus session.

Add YouTube as a site rule, opt it into Focus, and keep the boundary active for the short session you choose.

Version note: these instructions describe Little Pause 3.1.0. The Chrome Web Store currently offers Talk to Unlock 3.0.1 with an earlier interface. Compare the installation options.

This guide covers the site-specific Focus setting. It does not permanently block YouTube or change any rule you have not selected.

1. Add YouTube to My sites

After installing Little Pause, open its popup and choose My sites. Add youtube.com. Turn on Include subdomains if you want the same boundary to cover YouTube subdomains that your browsing uses.

2. Choose the normal site behavior

For a firm boundary during ordinary browsing, choose Keep blocked. If you want a lighter boundary outside Focus, choose Take a pause instead. The site rule still controls its normal behavior when no Focus session is running.

3. Opt YouTube into Focus

Open the YouTube rule’s More options and enable Keep this site blocked during Focus sessions. Save the rule. Focus overrides the rule’s schedule for opted-in sites until the session expires.

4. Start a short Focus session

  1. Open the Little Pause popup.
  2. Choose 25 min, 50 min, or Custom.
  3. Press Start focusing.
  4. Open your next task in another tab. YouTube remains protected while the session is active.

The session is stored locally and uses a Chrome alarm for expiry, so it can continue across a browser restart when Chrome restores the extension.

5. End or adjust the session

When the session ends, the normal YouTube rule applies again. You can end the session from the popup at any time. To change only the Focus behavior, edit the YouTube rule rather than changing the global protection profile.

If you need YouTube for a real task

When emergency access is enabled, the blocker provides its five-second hold-to-confirm action under Need to continue?. An interrupted hold does not unlock the site. A completed bypass grants the rule’s normal unlock window and creates a local activity event.

Keep it adjustable: use a 25-minute Focus session first. If that feels too long, end it and try a smaller boundary next time. The aim is a usable choice, not a perfect streak.

Troubleshooting

  • If YouTube is still available during Focus, check that the rule is enabled and the Focus option is saved.
  • If a page was already open before the rule changed, reload that page.
  • If a schedule seems to conflict with Focus, remember that Focus is the higher-priority override for opted-in sites.
  • If you want a pause rather than a hard block, change the normal method to Take a pause; Focus behavior remains a separate option.
