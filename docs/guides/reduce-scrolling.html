How to reduce distracting website visits.

The goal is not to make the internet disappear. It is to create enough space between the impulse and the click to make a more useful choice.

Version note: these instructions describe Little Pause 3.1.0. The Chrome Web Store currently offers Talk to Unlock 3.0.1 with an earlier interface. Compare the installation options.

This guide is for anyone who wants a smaller boundary around a few websites, not a rule for the whole internet.

1. Notice the sites that take you somewhere else

For a day or two, notice which domains you open without meaning to. You do not need a perfect list. Start with one or two sites that regularly interrupt work, rest, or conversations. Name the specific pattern: opening a feed between tasks, checking video during a writing block, or reopening a site after you already decided to stop.

2. Add only those sites

Little Pause works best when the boundary is specific. After installing the extension, open My sites, add a domain such as youtube.com, and include subdomains only when you need them. Leave everything else alone. A smaller list is easier to understand and trust.

3. Start with a ten-second pause

Choose Take a pause for a light-touch reset. When the blocker appears, press its explicit start button, let the ten seconds pass, and then decide whether you still want to continue. The pause is a prompt, not a judgment, and the browser demonstration on the home page shows the idea without blocking this site.

4. Make the boundary fit the site

Use Say a phrase when speaking a deliberate intention helps, and Keep blocked when you want a stronger edge. Schedules, daily allowances, cooldowns, unlock duration, and the five-second emergency hold are under that site’s More options. Keep the everyday choice visible and put extra complexity behind the setting that needs it.

5. Give the next action somewhere to go

Before a focus session, decide what you want to return to: a document, a walk, a message, or a few minutes of rest. The pause works better when it opens onto something concrete. If you are trying a timer too, the guide to short Focus sessions explains how to choose a realistic duration.

Try it gently: protect one site for one afternoon. If the boundary feels too heavy, make the pause shorter, change the method, or remove the rule. Useful friction should remain adjustable.

Where Little Pause fits

Little Pause is a Chrome extension for selected websites, not a replacement for every habit or a guarantee of productivity. It gives you a configurable moment before a chosen distraction. Read how to pause before opening a distracting website for the exact setup.
