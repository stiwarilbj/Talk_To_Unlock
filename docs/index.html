Three ways to pause

Choose the boundary, site by site.

There is no one right level of friction. Little Pause lets you set a different response for every site.

Take a pause

Best for a light touch. Start a ten-second pause, then choose whether you still want to continue. The default for new sites.

Say a phrase

Best when intention helps. Speak the phrase you set for the site. Voice is optional and audio is never saved.

Keep blocked

Best for a firm edge. Keep the site closed until your rule allows it, with emergency access still available when enabled.

Questions, answered

No mystery settings.

Is Little Pause in the Chrome Web Store?

The published store version is Talk to Unlock 3.0.1, the earlier name and interface. Little Pause 3.1.0 is the newer manual build. Compare installation options before choosing.

Does Little Pause block the whole internet?

No. It only applies rules to domains you add in My sites. Chrome content scripts can evaluate eligible pages so the extension can notice a matching rule.

Is my voice recorded?

No audio or recognized transcript is stored. Browser speech processing and microphone availability depend on Chrome and your device. See the privacy page.

Can I use it without voice?

Yes. Every site can use a timed pause or a hard block. Voice is optional and only appears for Voice rules.
