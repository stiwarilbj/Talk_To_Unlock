Start with a little pause

Install Little Pause in Chrome.

Choose the published Chrome Web Store release, currently called Talk to Unlock, or the newer Little Pause manual build. They are two versions of the same project.

Chrome Web Store: Talk to Unlock 3.0.1

The published store release includes website rules, optional voice checks, timed pauses, and Focus sessions. It uses the previous name and interface. The Little Pause screenshots and walkthroughs on this website show version 3.1.0.

Open Chrome Web Store

  1. Open the listing and check that the developer is Shantanu Tiwari, offered by Gitchub.
  2. Select Add to Chrome and review Chrome’s permission prompt.
  3. Pin Talk to Unlock, open its settings, and choose the websites and rule methods you want.

For the simplified Little Pause interface, use the manual build below. Avoid running both versions on the same sites, as their blockers can overlap.

Manual download: Little Pause 3.1.0

Little Pause 3.1.0

Manual Chrome build · local-first · no account required

Download ZIP

Load the extension

  1. Download the ZIP above and unzip it somewhere easy to find. Select the extracted folder that contains manifest.json, not the ZIP itself.
  2. Open chrome://extensions in a Chrome tab.
  3. Turn on Developer mode in the top-right corner.
  4. Choose Load unpacked, then select the extracted Little Pause folder.
  5. Pin Little Pause from Chrome’s extensions menu so the pause and Focus timer are close by.
First use: Little Pause starts with no preset sites. Open the popup, choose the sites you want help with, confirm the pause method, and try the short demonstration. Nothing is silently enabled for a fresh install.

After installation

Use the popup for protection status, the 25-, 50-, or custom-minute Focus timer, and your site list. Open My sites for schedules, daily limits, cooldowns, voice effort, timed fallback, and Focus behavior.

Need a hand? Visit Help, read how to pause before opening a distracting website, or browse the practical guides.

Moving between store and manual versions

Chrome treats store and unpacked installations as separate extensions. Export your configuration from the old installation and import it into the new one after reviewing the replacement confirmation. Activity, unlock grants, and active Focus sessions are not included. Disable the old installation after checking your rules.

Update an existing manual install

Export your configuration from Settings first. Keep the same unpacked folder used by Chrome, replace its files with the newer release, return to chrome://extensions, and select Reload. Loading the new release from a different folder can create a different unpacked extension identity, so keeping the folder is the safest way to preserve local storage.

What this download is

This is a free, manually installed Manifest V3 extension for Chrome. This ZIP is separate from the store release above. Chrome may show a Developer mode notice for unpacked extensions.
