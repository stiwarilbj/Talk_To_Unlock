Install Little Pause in Chrome.

The extension is not in the Chrome Web Store yet. Download the current build, unzip it, and load the folder through Chrome’s Developer mode.

Download ZIP

Load the extension

  1. Download the ZIP above and unzip it somewhere easy to find. Select the extracted folder that contains manifest.json, not the ZIP itself.
  2. Open chrome://extensions in a Chrome tab.
  3. Turn on Developer mode in the top-right corner.
  4. Choose Load unpacked, then select the extracted Little Pause folder.
  5. Pin Little Pause from Chrome’s extensions menu so the pause and Focus timer are close by.
First use: Little Pause starts with no preset sites. Open the popup, choose the sites you want help with, confirm the pause method, and try the short demonstration. Nothing is silently enabled for a fresh install.

After installation

Use the popup for protection status, the 25-, 50-, or custom-minute Focus timer, and your site list. Open My sites for schedules, daily limits, cooldowns, voice effort, timed fallback, and Focus behavior.

Need a hand? Visit Help, read how to pause before opening a distracting website, or browse the practical guides.

Update an existing install

Export your configuration from Settings first. Keep the same unpacked folder used by Chrome, replace its files with the newer release, return to chrome://extensions, and select Reload. Loading the new release from a different folder can create a different unpacked extension identity, so keeping the folder is the safest way to preserve local storage.

What this download is

This is a free, manually installed Manifest V3 extension for Chrome. It is not a Chrome Web Store listing, and Chrome may show a Developer mode notice for unpacked extensions.
