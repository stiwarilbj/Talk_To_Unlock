Load the extension

  1. Download the ZIP above and unzip it somewhere easy to find. Keep the unzipped folder in place while you use the extension.
  2. Open chrome://extensions in a Chrome tab.
  3. Turn on Developer mode in the top-right corner.
  4. Choose Load unpacked, then select the unzipped Little Pause folder — the folder containing manifest.json.
  5. Pin Little Pause from Chrome’s extensions menu so the pause and Focus timer are close by.
First use: Little Pause starts with no preset sites. Open the popup, choose the sites you want help with, confirm the pause method, and try the short demonstration.

After installation

Use the popup for protection status, the 25-, 50-, or custom-minute Focus timer, and your site list. Open My sites for schedules, daily limits, cooldowns, voice effort, timed fallback, and Focus behavior.

Need a hand? Visit Help or read the guide to short focus sessions.

Updates

This page provides the current manual build. To update, download a newer ZIP, unzip it to a new folder, and use Load unpacked again. Chrome will retain extension storage when the extension identity remains the same.
