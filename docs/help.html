A hand when you need one

Help for the next small step.

Little Pause is intentionally small. These answers cover setup, site rules, Focus sessions, voice checks, and the most common Chrome snags.

Quick setup

  1. Use the installation page to download and load the folder unpacked.
  2. Open the Little Pause popup and choose the sites you want to protect. Fresh installs do not add a preset list for you.
  3. Choose Take a pause for a simple ten-second boundary. You can switch any site to a phrase or a hard block later.
  4. Choose Start focusing in the popup for 25, 50, or a custom number of minutes.

Something is not working?

The blocker does not appear

Check that the site is enabled in My sites, protection is on, and the site’s schedule is active. Reload the page after changing a rule. Browser-internal pages such as chrome:// are not available to extension content scripts.

Voice is unavailable

Voice requires Chrome speech recognition and microphone access. If the browser denies access, the rule can offer its configured timed fallback. In a browser without speech support, use a pause rule instead. Little Pause closes the microphone stream after each attempt.

The pause was interrupted

Start the pause again and keep the tab visible. If you need to continue immediately, use the five-second hold under Need to continue? when that rule permits emergency access.

Focus ended after a restart

Focus sessions are stored locally and use a Chrome alarm for expiry. If a session is still active after Chrome restarts, the popup shows its remaining time. A session can only protect sites whose Keep this site blocked during Focus sessions setting is enabled.

Data and configuration

Use Settings to export a versioned JSON configuration or import an earlier Talk to Unlock v3 export. Imports are validated and confirmed before replacing settings; existing activity and unlock windows are not taken from the file. See Privacy for storage details.
